Privacy Policy

Pino minimizes what leaves your browser.

Pino does not require an account and does not collect your email address, browsing history, payment details, analytics, or advertising identifiers. Your Perplexity API key is stored in this Chrome profile, not on a Pino server. When you explicitly request a fact-check, Chrome sends the selected claim, limited nearby text, the page title, an available publication date, and the page URL without query parameters directly to Perplexity over HTTPS. Perplexity processes that request under its own privacy policy. Pino does not keep a developer-side copy of the request or result. You can remove the API key at any time from the Pino popup or remove all extension data by uninstalling Pino.

Effective July 16, 2026 · Version 3.0

Who operates Pino?

Pino is an independent open-source project maintained by Iacob Paștina in Bucharest, Romania. Questions or deletion requests concerning legacy Pino account data can be sent to iacobpastina@gmail.com.

What data does Pino handle?

Data stored in Chrome

  • Your Perplexity API key.
  • Your selected Perplexity model: Sonar or Sonar Pro.

This data is stored with chrome.storage.local. It is not synced through your Google account. On supported Chrome versions, Pino restricts this storage to trusted extension contexts so webpage content scripts cannot read the key.

Data sent when you request a fact-check

  • The text you explicitly selected.
  • Up to 3,000 characters of nearby text to reduce ambiguity.
  • The page title and an available publication date.
  • The page URL after query parameters and fragments are removed.
  • Your API key in the HTTPS authorization header.

Pino does not send the full article or page. It does not run fact-checks in the background. The transfer happens only after you choose “Fact-check with Pino.”

Where does the request go?

The extension sends the request directly from Chrome to the Perplexity API. Pino does not proxy it through a developer server. Perplexity is an independent service and handles the request under the Perplexity Privacy Policy and its API terms.

Does Pino collect emails or payment details?

No. Version 3 has no Google sign-in, account registration, newsletter signup, checkout, subscription, credit system, or paid unlock. Any API charges are between you and Perplexity; Pino does not receive your Perplexity billing information.

How long is data retained?

Pino does not retain fact-check requests or results on a developer server. The API key and model choice remain in Chrome until you remove them or uninstall the extension. Perplexity controls its own API retention practices.

What about data from versions before 3.0?

Older Pino versions used Google sign-in, Supabase, and Stripe. Version 3 removes those services from the extension and deletes cached authentication and billing state during migration. Legacy server-side account or transaction records may still need to be retained temporarily for legal, fraud-prevention, accounting, or dispute purposes. Contact the address above to request access or deletion where applicable.

How can you delete local data?

  • Open the Pino popup and choose Remove to delete the API key.
  • Uninstall Pino from Chrome to remove all extension-local data.
  • Revoke the API key in the Perplexity console if you believe it was exposed.

Chrome Web Store Limited Use disclosure

Pino's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data accessed through extension permissions is used only to provide the user-requested fact-checking feature. It is not used for personalized advertising, sold, transferred for unrelated purposes, or made available for human review except where required for security, support with the user's consent, or legal compliance.

Children's privacy

Pino is not directed to children under 13 and does not knowingly collect personal information from children.

Changes to this policy

Material changes will be published on this page with a new effective date. Changes that require new Chrome permissions will also appear in the Chrome update flow.
